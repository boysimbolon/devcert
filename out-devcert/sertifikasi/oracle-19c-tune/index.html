Oracle 19c Performance Management & Tuning

Tuning database Oracle 19c: wait events, time model, AWR/ASH/ADDM, Statspack, execution plan, statistik, SPM, memori (SGA/PGA/IM), I/O, dan Real Application Testing.

Kode ujian1Z0-084
Durasi90 menit
LevelOCP (lanjutan)
FokusDiagnosis berbasis bukti
0 dari 46 topik
Mulai ujian latihanSoal pilihan ganda, ada timer dan pembahasan.

Rencana belajar

  1. Pekan 1

    Metodologi, siklus tuning, time model, wait events, dan V$ views.

  2. Pekan 2

    Statspack, alert log, trace file, metric/alert, dan AWR baseline.

  3. Pekan 3

    ADDM, ASH, maintenance task, monitoring operasi dan service.

  4. Pekan 4

    Fase SQL, execution plan, trace, adaptive plan, dan SQL Plan Directives.

  5. Pekan 5

    Statistik & parameter optimizer, lalu biaya operasi SQL (shrink, chaining, kompresi, ruang).

  6. Pekan 6

    Real Application Testing (SPA, Replay) dan SQL Performance Management (SPM, advisor).

  7. Pekan 7

    Shared pool, buffer cache, I/O, Big Table Cache, dan Flash Cache.

  8. Pekan 8

    PGA, temp, ASMM/AMM, In-Memory Column Store, lalu ujian latihan penuh.
