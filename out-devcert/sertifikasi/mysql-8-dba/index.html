MySQL 8.0 Database Administrator

Sertifikasi OCP untuk DBA MySQL 8.0: arsitektur InnoDB, instalasi, security, monitoring, optimasi query, backup, dan replikasi sampai InnoDB Cluster.

Rencana belajar

  1. Pekan 1

    Architecture: koneksi, datadir, InnoDB, buffer pool, data dictionary.

  2. Pekan 2

    Installation: paket, file, start/stop, upgrade, option file, variabel, multi-instance.

  3. Pekan 3-4

    Security (domain terbesar): user, role, plugin auth, TLS, password, enkripsi, firewall.

  4. Pekan 5

    Monitoring: log, status, audit, kapasitas, lock dan deadlock.

  5. Pekan 6

    Query Optimization: EXPLAIN, index, statistik, performance_schema.

  6. Pekan 7

    Backup: jenis, strategi, MEB, mysqldump, raw file, binlog + PITR.

  7. Pekan 8

    HA: replikasi, multisource, thread, troubleshooting, InnoDB Cluster dan recovery.
