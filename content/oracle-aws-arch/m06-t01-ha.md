## Kenapa topik ini diuji
Soal skenario menanyakan desain minimum untuk target RTO/RPO tertentu.

## Konsep inti
```text
Tingkat 1: satu VM cluster (Exadata = RAC) -> node failure tidak menghentikan database
Tingkat 2: Data Guard ke AZ/region lain -> kegagalan zona/region
Tingkat 3: backup + restore -> pemulihan bencana besar (RTO jam)
```

Oracle Database@AWS berjalan pada satu AZ per ODB network; karena itu **HA lintas AZ memerlukan Data Guard** (atau replikasi lain), bukan asumsi otomatis.

## Jebakan
- Menganggap satu VM cluster melindungi dari kegagalan AZ.
- Tidak menguji switchover Data Guard.
- RTO/RPO tidak didefinisikan sehingga desain tidak terukur.
- Aplikasi tidak mendukung reconnect/failover cepat.

## Latihan
1. Komponen HA di dalam satu VM cluster?
2. Bagaimana melindungi dari kegagalan AZ?

<details><summary>Jawaban</summary>
<p><b>1.</b> RAC (instance ganda pada Exadata).</p>
<p><b>2.</b> Data Guard ke cluster di AZ/region lain.</p>
</details>
