## Kenapa topik ini diuji
Soal menanyakan perbedaan switchover dan failover serta mode proteksi.

## Konsep inti
| Mode | Perilaku |
|---|---|
| Maximum performance | asinkron, RPO > 0, dampak minimal |
| Maximum availability | sinkron bila memungkinkan |
| Maximum protection | sinkron ketat, bisa menghentikan primary bila standby gagal |

**Switchover**: peralihan terencana, tanpa kehilangan data. **Failover**: peralihan darurat saat primary tidak tersedia.

```sql
-- pada standby
ALTER DATABASE RECOVER MANAGED STANDBY DATABASE DISCONNECT FROM SESSION;
-- switchover
ALTER DATABASE COMMIT TO SWITCHOVER TO PRIMARY WITH SESSION SHUTDOWN;
```

## Jebakan
- DR tidak diuji → switchover gagal saat dibutuhkan.
- Secondary region dengan kapasitas lebih kecil tidak mampu menanggung beban penuh.
- Aplikasi masih menunjuk endpoint lama.
- Backup dan DR dianggap saling menggantikan.
